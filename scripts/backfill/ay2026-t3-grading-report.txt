DECISIONS FOR A PERSON BEFORE APPLYING
--------------------------------------
  1. 6 student(s) get a different grade because the workbook's SAVED percentages are stale —
     the marks and the row totals are right, the percentage cells were never recalculated. The SIS
     stores what the workbook's own formula gives (6 higher, 0 lower). If the workbook
     grade was already reported to parents, confirm with the teacher which grade stands; the marks
     themselves need no change. (MATH S1 Discipline 1)
  2. 1 student(s) had a blank slot left OUT of their total in the workbook (the SIS counts it
     as zero, KD #225). After the apply, the registrar can untick exactly the slot(s) named in the
     mismatch list under "Counted assessments"; the SIS grade then equals the workbook's. The import
     does not excuse slots itself (manual by design; the derive trigger refuses it outside the registrar).
  3. Lock the sheets? T2's import locked every sheet it wrote ("backfill-import"). This apply leaves the
     T3 sheets UNLOCKED so the registrar can make the excusals above without a change request;
     lock them afterwards (Markbook bulk lock) if T3 is final.
  4. Teacher names on the SIS sheets are not changed (many workbook tabs have a blank "Teacher:" line).
  5. The SIS max scores are REPLACED by the workbook's on all 118 sheets (the SIS still holds the
     generated placeholders). No subject weight is changed. Workbook headers that disagree with the SIS
     subject weights: 0. Sheets given their own weights because a component is off: 0.
  Apply order: the primary and secondary files are independent; run each whole file in one go.
