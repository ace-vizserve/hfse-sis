**Sprint 53 footgun (2026-06-03) — namespace the URL state.** `url={{ enabled: true }}` WITHOUT a `namespace` makes `useUrlState.read()` treat **every** non-reserved page query param as a phantom facet column-filter. On a page carrying its own param (e.g. `?term_id=`), the shell's per-tab count logic (`tabCountData`) mis-applies it — reads `row[param]`, which doesn't exist on the row, so it excludes **every** row → all status-tab counts read **0** — while TanStack ignores the unknown column so the table still shows rows; `write()` would also strip the param on any filter change. **Fix: pass a `namespace`** so the table only reads/writes its own `ns.*` params and leaves the page's params alone (surfaced + fixed on the evaluation sections list → `namespace: 'sections'`). **Deferred:** 6 consumers still use `url={{ enabled: true }}` namespace-less (`grading-data-table`, `change-requests-data-table`, `audit-log-data-table`, `all-publications-overview`, `cohort-table`, `feedback-table`) — each safe only while its page carries no non-facet param; audit + namespace next pass (notably grading, which now receives the KD #75 `?section=` deep-link).

**Section-list conversion (Sprint 59, 2026-06-08).** The three remaining pill/card section lists — `/sis/sections`, `/markbook/sections`, `/attendance/sections` — were converted to `<DataTable>` (mirroring the already-tabled `/evaluation/sections`, KD #106): Level facet + search + CSV + sortable + `url={{enabled:true, namespace:'sections'}}`. Each row gets a `⋯` **row-actions menu** via a new shared **`components/sections/section-row-actions.tsx`** (`module: 'sis'|'markbook'|'attendance'`): "Open" (roster/grading/daily) always; **Generate index + Generate sheets gated to registrar/school_admin/superadmin** (hidden for teachers, who can still view Markbook/Attendance). The Generate-index confirm dialog was extracted into a controlled **`GenerateIndexDialog`** (`components/sis/generate-index-button.tsx`) reused by the standalone button + the row-actions; `GenerateSheetsDialog` is mounted controlled (its trigger self-suppresses when `open` is set with no `children`). **Headline:** Generate-index is now reachable from the **Markbook** sections row-actions, so the registrar no longer trips into SIS Admin to renumber a class (completes the KD #136 discoverability gap). Per-module columns kept lean (current data, no new queries): SIS = Active+Withdrawn, Markbook = Students, Attendance = Active. Markbook's page gained a small terms read for the `termStarted` Generate-index warning; Attendance preserves its form-adviser scoping. Three new `components/{sis,markbook,attendance}/sections-data-table.tsx`. Spec/plan: `docs/superpowers/{specs,plans}/2026-06-08-section-list-tables*`.

**Namespace footgun closed (Sprint 59, 2026-06-08).** The deferred namespace-less `url={{ enabled: true }}` consumers are now all namespaced — an in-session audit found the footgun had gone live because their pages carry non-facet params: **grading** (`?section=` publish-checklist deep-link, KD #75 — it was **blanking the grading list + zeroing tab counts**, the highest-impact one) → `namespace: 'grading'`; **change-requests** (`?req=/action=/sheet_id=`) → `'requests'`; **cohort-table** ×5 (`?ay=`) → `'cohort'`; **feedback** (`?ay=`) → `'feedback'`; **all-publications-overview** (`?section_id=`) → `'publications'` (audit-log already had `'al'`). `rg "url={{ enabled: true }}"` now returns nothing. The grading page's RSC also switched its `initialSearch` read to the namespaced `grading.q` key (+ pruned dead never-read filter-param declarations). Same audit also fixed: the **evaluation priority-panel "submitted" count** now requires submitted **+ non-empty** (KD #120 — it was count-only, mis-counting emptied-but-submitted write-ups; both teacher + registrar sites), and a **guard comment** on `POST /api/attendance/import` documenting it lacks the single-writer's `assertAdviserForSections` scope check (teachers are excluded today, so no bypass — but widen the role list and a teacher could import any section). The audit otherwise came back clean (no `grade_entries` phantom-column bugs, transfer-safe roster counts, count==drill aligned, live-state metrics today-anchored, no Next-16 server-only/cache/async-params violations). No migration.

**Deep-link + url-state completion sweep (Sprint 59, 2026-06-09).** Follow-on once the table url-state was namespaced: a deep-link's query params must match the **destination table's filter contract** — namespaced key + the cell **value** (a name/label), never a raw id. **(1) Grading regression fixed** — the KD #84 namespace rename had stranded grading's inbound deep-links on the old un-namespaced `?q/?status/?mine/?term` + a raw `?section=<id>` server-scope, so they stopped hydrating the table. Added an exact **Section facet** to the grading table and repointed every inbound link (sections CTA, drills, dashboard cards, sidebar "My sheets", publish-window panel + bulk dialog) to `grading.section=<name>` / `grading.*`; dropped the server-side `?section=<id>` scope (stats now AY-wide, table filters client-side). **(2) Full inbound-link audit (3 parallel agents, all modules):** no other id-instead-of-value or namespace-mismatch deep-links exist — every other inbound link is server-scope (page-RSC reads `?ay/?req/?sheet_id/?status/?expiring/?section_id`, un-namespaced + ids OK) or already correct. **(3) Four filterable tables had NO url-state** (filters lost on refresh, not shareable) → namespaced url-state added: `<StudentDataTable>` (`/records/students` + `/admissions/applications`) → `'students'`; `discount-codes-data-table` → `'discounts'`; the two p-files document-validation queues (same page) → `'awaiting'` + `'expiring'` (distinct so they don't collide). Intentionally-disabled tables (roster detail views, "my requests") + the server-filtered audit-log/p-files-dashboard surfaces left as-is. No migration.
