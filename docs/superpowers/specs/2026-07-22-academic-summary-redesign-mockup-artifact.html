Academic Summary → module pages · three-tier template

One shared page shape, rendered in the app's own design system. Every page reads top-to-bottom as ① stat row → ② analytics → ③ filterable detail table. Below is the canonical page (Awards, on Markbook) in full; the bottom strip shows how Attendance and Comments fill the identical three tiers.

Signature: a single gold / silver / bronze colour thread runs from the stat tiles → the distribution donut → the table badges, so the key and the data always share the same paint (design-system §10). Everything else stays quiet and on-token.

Notes for review

One deliberate deviation from the stock stat card: the Gold / Silver / Bronze tiles are tinted to their tier (amber / slate / bronze) instead of the default indigo — because on an awards page the tile colour is the data. It needs a one-line MetricCard prop (tileClassName) or a small page-local card; the plan will pick one. Everywhere else the stock component is used unchanged.

On-token throughout: no bg-white, no raw hex — every swatch is a real globals.css Aurora Vault value. (Fonts here fall back to system serif/mono; the app ships Source Serif 4 + JetBrains Mono.)
