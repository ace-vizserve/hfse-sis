Roomier than the first pass

Rows breathe at 20px, avatars are 44px, and the panel is 552px wide. Everything still lands on the project's 16 / 24 / 32 / 48 rhythm — this just moved up a step on it rather than inventing new spacing.

The number still means one thing

Three items are waiting on you, so the icon shows 3 and the pinned block holds exactly those three. Everything below is history — it never touches the count.

Pinned sits above the tabs, not inside General

What you owe someone doesn't change depending on which tab you're reading, so it stays put. This is one step further than we discussed — say if you'd rather it lived inside General.

Colour is spent in exactly one place

The small mark on each circle, in the same three tones every status badge in the SIS already uses: mint for went through, red for turned down, indigo for newly filed. The circle itself stays the standard gradient, so the log stays scannable without becoming a fruit salad.

No spine in the log

A connecting line would say these events belong to one sequence. They don't — three different children's filings interleave here. The line appears in Plate B, where the order genuinely is the content.

"Show older activity" is a real button

It also fires on scroll, but a keyboard user has to be able to reach it, and an infinite list with no control reads as broken when it stalls.

The spine earns its place here

These four rows are one ladder in order, so the line carries real information: where it started, where it stopped.

A turned-down filing needs the fourth row

A rejection stops the ladder, and in the database the later steps sit at "waiting" forever. Drawn as pending they'd read as still coming. Drawn hollow with a dashed line, they read as what they are — never reached.

Oldest first, unlike the panel

Here you're reading a story rather than checking what's new.

The footer states the outcome plainly

Whether the register was touched is the question people actually open this for. It shouldn't need inferring from the rows.

Proposed

The badge doesn't move

Same position, same red, same meaning — only the glyph changes. If people have learned where their count lives, it stays there.

An empty panel is not a broken one

Most staff are on very few approvals. The empty state says what would appear here, so a quiet panel reads as quiet rather than failed.

Four things to look at

  1. The pinned block above the tabs. I moved it out of General so it's always visible. If you'd rather it sat inside the General tab as we said, that's a one-line change.
  2. "Mark changes" as the tab label. The pages call it change requests. Teachers call it a mark change. I've used the teachers' words — tell me if the page title should win instead.
  3. Whether the log is too chatty. Every step of every approval you're on produces a row, so a busy adviser could see six rows for one child's filing. The alternative is one row per approval that updates in place — less faithful to "every action appears", but shorter.
  4. The outcome line. "1 day marked as excused on the register" is the thing no screen says today. Check the wording is what you'd want a teacher to read.
