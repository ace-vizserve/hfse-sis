Why this shape

Decisions

No big percentage at the top That's the registrar's question. An adviser's term rate barely moves day to day; putting it in the hero would push the one thing that changes daily below it.
Nothing school-wide, anywhere Attendance is adviser-only at the database. Every number here is built from the adviser's own sections, so the page cannot leak what KD #163 just closed.
The strip shrinks when you're done Two marked classes become one sentence, not two green cards. Absence of work should look like absence, not like more content.
Holidays are stated, not implied A day nobody should mark never renders as an outstanding task — it says which holiday, and when the next school day is.
