HFSE SIS · SIS Admin · Visual redesign

The admin hub as a command centre, not a menu

The navigation restructure already shipped (3 sidebar tiers, merged pages, one audit surface). This preview adds the missing layer: the look. The hub opens with the year's state as one glance — a segmented readiness band, a tight stat row, an attention feed — and puts the five most common tasks one click away. Modeled on how Veracross builds its admin homepages (status + launchpad), kept in HFSE's own visual language: serif headlines, mono eyebrows, solid tints, hairline borders. No gradients, no centered heroes.

Screen 1 · The hub — /sis

The signature element: the year band — setup readiness as a segmented bar with a serif fraction and the page's single primary button. Below it, everything is status or a launch point. Nothing here duplicates the sidebar.

What changes in code

Hub rebuild — one file

`app/(sis)/sis/page.tsx` recomposes the kept blocks into this layout: the year band replaces the Year-Setup card (same `getAyReadiness` data), the stat band restyles the four existing KPIs, "Needs attention" merges the class-assignment callout + pending change requests + level-demand signals into one feed, "Coming up" restyles the events card, and the quick-actions row is new (links + one dialog trigger). All existing loaders — no new queries except reusing `computeLevelDemand`.

Sidebar polish — group chrome only

Cadence hints (weekly / yearly / rare) on the three group headers and count badges on AY Setup readiness, Sections, and Staff — data the sidebar's realtime-badge slot already supports. Item styling unchanged (existing active-wash recipe).

Staff header — presentation only

The shipped two-cut page keeps its logic; the header gains the count-badged segmented tabs, and rows gain initial-tile avatars + role chips + assignment chips (data already loaded by StaffTable). The table keeps sorting/filtering underneath.

Bindings & references

Everything uses existing Aurora Vault tokens — no new colors, no gradients on content, solid tints on size-8/10 tiles, serif/mono voices per the design system. Pattern reference: Veracross Axiom admin homepages (status + launchpad); click-depth norm ≤2 from the benchmark study.

Preview only — links are inert. All values shown are illustrative. The standing rule applies: colors are never the only signal (every status carries an icon or text), and the page keeps exactly one primary button (the year band's CTA).
