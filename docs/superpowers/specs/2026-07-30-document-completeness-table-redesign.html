P-Files · Proposed redesign

Document Completeness

The table's job is chase work: who owes us a document, which one, and can I nudge them from here. Thirteen columns of coloured dots answer none of that without hovering. This replaces them with one strip and a short list of what's actually outstanding.

Today

What ships now

Reproduced from document-completeness-table.tsx. Names are made up — real students aren't in this file.

No legend exists The only explanation of a colour is a native title= tooltip. Colour is the sole signal — that fails §9 and anyone not using a mouse.
Seven states, five colours Lapsed and Sent back both paint bg-destructive; Not collected and N/A both paint bg-muted. Two pairs are undecodable even with a legend.
Names get the leftovers Thirteen slot columns take the width first, so names wrap to three lines and every row is a different height.
The useful column is off-screen Completeness sits past a horizontal scroll, behind the dots it summarises.

Proposed

Six columns, nothing hidden

Same data, same rows, same shell — only the columns change.

Document completeness

Per-student breakdown for renewals. Open a student to upload or record a document.

Detail on demand

The full thirteen, when you want them

Clicking a strip opens all thirteen slots named in full, with expiry dates — the same disclosure pattern the admissions pipeline strip already uses (pipeline-strip.tsx, KD #152).

Rationale

Why each change

One strip, not 13 columns
Segment order is fixed, so you can still compare down the column the way the matrix let you — in 112px instead of ~520px. Reuses the shape of PipelineStrip, which solved this same problem for nine admissions stages.
Colour means action, words mean cause
Five fills, each one distinct thing to do: nothing, check it, wait on the parent, chase a re-upload, collect it. Lapsed vs sent back share a fill because the officer's next move is identical — the chip's icon and word carry the difference. Six swatches, six meanings, no duplicates (§10.5).
Outstanding is a list, not a puzzle
The exceptions are named in words: Mother Passport, Birth Certificate. Three fit; the rest collapse to a count. On a chase surface the exceptions are the whole point, so they get the widest column.
Completeness reads as a ratio
9/13 in tabular mono beats a 69% pill — the officer collects documents, not percentages, and it sorts identically. It sits directly above the strip it describes.
A legend that is a real key
Swatch and segment read one exported map, so they cannot drift (§10.2). It's always visible above the table, not hover-only.
Fixed row height
Nothing wraps. Name and number stay on one line, so the eye tracks straight down the column.
Remind stays on the row
Unchanged behaviour — it still opens the existing notify dialog. It just stops competing with 13 dots for attention.
