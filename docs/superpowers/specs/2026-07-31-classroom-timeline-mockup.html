Classroom · Timeline · Proposed

Fifty rows that all look the same aren't a timeline.

The tab shows the last fifty things that happened in a class. Today it renders them as one flat slab where the loudest element — a coloured pill — is usually the same word forty times running, and most rows carry no detail at all.

Today

What it looks like now

Four rows of the fifty. Names are made up.

The date repeats fifty times Every row prints the full 31 Jul 2026, 14:32 down the right edge, so the column carries almost no information per line.
The badge is the loudest thing and says the least Forty consecutive "Write-up submitted" pills. Repetition becomes the dominant visual and the eye gets no signal.
Most rows have no content line When an audit row carries nothing summarisable the humanizer returns "—", so a typical row is a badge, an email and a time around no information.
The actor is a raw email, every time The same address on forty rows, when the app already has a staff name map and an initials-avatar convention.

Proposed

Grouped by day, collapsed by run

Same fifty events, same humanizer. What changes is that repetition is treated as repetition instead of as fifty separate facts.

Why

Decisions

Runs collapse, and that's the whole fix Seven write-ups saved back-to-back by one person is one event with a count and a time span, not seven rows. Expanding shows the individual entries.
The day is a heading, the row keeps the time Fifty full dates become four sticky headings and fifty short times. The heading follows you down the scroll so you always know where you are.
The badge becomes a dot on the spine Colour still encodes the kind of event, but it stops shouting. The action name is now the row's own text, which is what you were reading anyway.
A dash is not information When the humanizer has nothing to summarise, the line is omitted rather than printing "—". An empty row should be short, not padded.
