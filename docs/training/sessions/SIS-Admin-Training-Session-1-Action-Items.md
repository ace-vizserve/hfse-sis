## D. Bugs from the live demo

- ✅ **B1 — FIXED.** Section assignment failed live with DB error "**plus updated by does not exist**," on both the "Students Needing Setup" and admissions "Assign a class" paths. **The column is `classUpdatedby`** — eight of the nine `*Updatedby` columns on the frozen admissions DDL lost the capital B, and `orientationUpdateby` also lost the "d". Verified in code 2026-08-24 (`lib/schemas/sis.ts:1092`, `lib/sis/section-transfer.ts:344-348` — which carries a comment explaining the lower-case b so nobody "corrects" it back).

  ⚠ **Three more defects were sitting in the same path, all found while fixing this one.** The same key in `section-transfer.ts` had been failing **silently** — PostgREST rejects the whole statement and that call site only warned — so every section transfer had been leaving `classSection` stale. A single-student sync could not see a section's other index numbers so it always asked for #1 (withdrawn students keep theirs). `transfer_student_section` always INSERTed, so moving a student **back** to a section they had left collided with the row they left behind — **migration 119** reuses that row and keeps its original number. And "Students needing setup" asked whether a `students` row existed, which is the person rather than the enrolment, so a failed assign hid the student from the one screen that could have fixed them. `[38:23, 39:08, 40:27]`
