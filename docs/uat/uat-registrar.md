### Sections

| #    | Area     | What the system does                                                                                                                                                                                                                                                                                                                                                                    | Correct? (Yes / No) | If not, the correct process |
| ---- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | --------------------------- |
| R-06 | Sections | The "Generate class index" button (on the Sections page) numbers every student in a class alphabetically by surname — the same way classes are numbered at the start of the year. Students who have withdrawn keep their number; those numbers are never reused. Late enrollees and students who transferred into the class mid-year are added at the bottom in the order they arrived. |                     |                             |
| R-07 | Sections | Once a term has already started, clicking "Generate class index" shows a stronger warning before you confirm — because re-numbering after the year has begun is unusual and may affect printed rolls. The button still works if you confirm; it is not blocked.                                                                                                                         |                     |                             |
| R-08 | Sections | Moving a student to a different class (section transfer) only works within the same year level. If you try to move a student to a class in a different level the system rejects it. A class is also capped at 50 students — the system rejects a transfer if the target class is already full.                                                                                          |                     |                             |

### Attendance

| #    | Area       | What the system does                                                                                                                                                                                                                                                                                           | Correct? (Yes / No) | If not, the correct process |
| ---- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | --------------------------- |
| R-09 | Attendance | A student who joins part-way through the year is only counted from their joining date. For the terms before they joined, their attendance shows as blank — not counted as absences. Their absence rate and attendance totals only reflect the period they were actually enrolled.                              |                     |                             |
| R-10 | Attendance | When a student goes over their allowed leave quota (for example, a second Vacation Leave in the same term), the system shows a warning but still saves the record. It does not block the entry — because attendance must record what actually happened, and you may be granting an exception.                  |                     |                             |
| R-11 | Attendance | There are three Excused (EX) subtypes: MC / Excuse Leave, Vacation Leave (allowed once per term), and Compassionate Leave (allowed up to 5 times per year). When you mark a student EX, you select the subtype from a dropdown. The cell shows "EX" in all cases; the subtype is stored for the quota reports. |                     |                             |

### Grading & Publishing

| #    | Area                 | What the system does                                                                                                                                                                                                                                                                                                                                                                                                                        | Correct? (Yes / No) | If not, the correct process |
| ---- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | --------------------------- |
| R-12 | Grading & Publishing | On a grading sheet, the QA (quarterly assessment) maximum score is adjustable — you can set it to match each assessment's actual total. The number of WW (written work) and PT (performance task) slots is fixed at 5 each per term.                                                                                                                                                                                                        |                     |                             |
| R-13 | Grading & Publishing | You can lock multiple grading sheets at once at the end of a term. On the grading sheets list, you select the sheets you want to lock and click "Lock selected." A confirmation appears before anything is locked. Already-locked sheets are skipped automatically.                                                                                                                                                                         |                     |                             |
| R-14 | Grading & Publishing | When a teacher submits a grade-change request (to fix a score on a locked sheet), the request is sent to the two designated approvers. Each approver receives an email with Approve and Reject buttons they can click directly from the email — no need to log in to the system to approve.                                                                                                                                                 |                     |                             |
| R-15 | Grading & Publishing | Before publishing a term's report cards for a class, a checklist shows which items are ready. Most items are soft warnings — you can still click "Publish anyway" if needed. However, there are two items that hard-block publishing and cannot be bypassed: (1) every student in the class must have a submitted adviser comment for every term being displayed on the card, and (2) the virtue theme for each displayed term must be set. |                     |                             |
| R-16 | Grading & Publishing | When publishing report cards for multiple classes at once, the system shows the readiness status for each class. Classes that are ready are published immediately. Classes that still have the hard-block items incomplete are skipped — they are not published, and you are told which ones were skipped and why.                                                                                                                          |                     |                             |
| R-17 | Grading & Publishing | The Academic Summary page (Records → Academic Summary) shows a school-wide overview of grades, awards, attendance, and adviser comments for all classes. From there you can generate and download the full Masterfile as an Excel file (.xlsx) or a CSV file — the data is not displayed as a scrollable grid on screen.                                                                                                                    |                     |                             |
