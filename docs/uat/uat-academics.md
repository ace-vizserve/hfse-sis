# HFSE SIS — Process Alignment · Academics

Below is what the system currently does for each task. Please tell us whether that matches how it _should_ work.

For each row: mark **Yes** if it's correct, or **No** and write the correct process in the last column. (No need to test anything — just confirm or correct.)

For: **Teachers + Academic Coordinator.**

---

### Markbook — entering grades

| #    | Area     | What the system does                                                                                                                                                                                                           | Correct? (Yes / No) | If not — the correct process |
| ---- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------- | ---------------------------- |
| A-01 | Markbook | You type raw Written Work, Performance Task, and Quarterly Assessment scores into the grading sheet. The system works out the percentage score and quarterly grade for you — you never write a formula.                        |                     |                              |
| A-02 | Markbook | Leaving a score cell blank means the student did not take that piece of work. It is excluded from the average — it does not count as zero. A score of 0 means they took it and scored zero, which is included.                 |                     |                              |
| A-03 | Markbook | Primary sections use weights of 40 % Written Work / 40 % Performance Task / 20 % Quarterly Assessment. Secondary sections use 30 % / 50 % / 20 %.                                                                              |                     |                              |
| A-04 | Markbook | For letter-graded subjects (Music, Arts, PE, Health Education, Christian Living, and similar), the quarterly cell shows a derived letter — A, B, C, or IP — worked out from the same WW/PT/QA scores.                          |                     |                              |
| A-05 | Markbook | For letter-graded subjects, you can override the derived letter with UG, E, or N/A for a specific student in a specific term. N/A means the student is not applicable for that assessment. UG and E are formal override codes. |                     |                              |

### Locked sheets and grade changes

| #    | Area          | What the system does                                                                                                                                                                                                                            | Correct? (Yes / No) | If not — the correct process |
| ---- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------- |
| A-08 | Locked sheets | When a grading sheet is locked at the end of a term, the score cells become read-only — you cannot type into them directly.                                                                                                                     |                     |                              |
| A-09 | Locked sheets | To correct a grade on a locked sheet, you file a change request: you propose the new value, give a reason, and pick an approver. The approver receives an email and can approve or reject it with one click from the email — no login required. |                     |                              |
| A-10 | Locked sheets | Once a change request is approved, the grade on the sheet updates to the new value and the change is recorded in the audit trail.                                                                                                               |                     |                              |

### Attendance marking

| #    | Area       | What the system does                                                                                                                                                                         | Correct? (Yes / No) | If not — the correct process |
| ---- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------- |
| A-11 | Attendance | In the Daily view, the whole class starts as Present by default. You only need to change the students who are absent, late, or excused — you do not have to mark every student individually. |                     |                              |
| A-12 | Attendance | The four attendance marks are P (Present), A (Absent), EX (Excused), and L (Late). Their colours match the colours used on the paper attendance sheet — blue, yellow, cyan, and pink.        |                     |                              |
| A-13 | Attendance | When you mark a student as Excused (EX), you choose the reason: MC / Excuse Leave, Vacation, or Compassionate. The reason is saved and feeds into the leave quota tracking.                  |                     |                              |

### Evaluation write-ups — form class advisers

| #    | Area       | What the system does                                                                                                                                                                                                                                                                                     | Correct? (Yes / No) | If not — the correct process |
| ---- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------- |
| A-14 | Evaluation | You write one holistic comment per student per term for Terms 1, 2, and 3. There is no adviser comment on the Term 4 (year-end) report card.                                                                                                                                                             |                     |                              |
| A-15 | Evaluation | The comment box is headed with the term's HFSE virtue theme — for example, "Form Class Adviser's Comments (HFSE Virtues: Integrity)". This heading comes from the virtue theme that has been set for that term.                                                                                          |                     |                              |
| A-16 | Evaluation | You can save a write-up as a draft without submitting it — it is saved but not yet finalised. When you are ready, you click Submit to finalise. A submitted write-up can be reopened and resubmitted if you need to change it.                                                                           |                     |                              |
| A-17 | Evaluation | A class's report cards for a term cannot be published to parents until every student in that class has a submitted (not just drafted) write-up for that term. Submitting your write-ups is what allows the report cards to be released.                                                                  |                     |                              |
| A-18 | Evaluation | Until a term's virtue theme has been set, you cannot write or edit your write-ups for that term — the comment fields stay locked. Once the registrar sets the theme (Evaluation → Virtue Themes), the fields open. This makes sure every comment is written under the correct virtue theme for the term. |                     |                              |
