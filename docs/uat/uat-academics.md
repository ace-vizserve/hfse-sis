# HFSE SIS — User Acceptance Testing: Teachers + Academic Coordinator

**What this is:** A checklist to confirm the system works the way you teach, grade, and mark attendance. Each row describes one behaviour — read the description, try it in the system, and mark whether it matches.

**How to fill it in:** Mark **Yes** if it works as described. Mark **No** if it does not — then write what the correct process should be in the last column. Leave the last column blank if you mark Yes.

**Who this is for:** Subject Teachers · Form Class Advisers · Academic Coordinator
