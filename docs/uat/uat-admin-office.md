## School Admin (SIS configuration)

| #     | Area                    | What the system does                                                                                                                                                                                                                                            | Correct? (Yes / No) | If not — the correct process |
| ----- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------- |
| AD-01 | AY setup                | Creating a new academic year pre-fills sections, subjects, and subject weights from the master template. You only need to add term dates — the structure is already there.                                                                                      |                     |                              |
| AD-02 | AY setup                | Setting a year as the current operational year automatically closes any previously-current year and opens its attendance-and-grading windows.                                                                                                                   |                     |                              |
| AD-03 | Early-bird applications | While the current school year is running, you can open next year's application intake early. Only one upcoming year can be open at a time. Closing or switching it is done in SIS Admin → AY Setup.                                                             |                     |                              |
| AD-04 | School calendar         | Each calendar date can be set as a school day, public holiday, school holiday, home-based learning day, or no-class day. Primary and secondary sections can have different day-types on the same date.                                                          |                     |                              |
| AD-05 | Subjects and weights    | When you update the maximum score for Written Work, Performance Task, or Quarterly Assessment on a subject configuration, the change automatically applies to all grading sheets for that subject that have not yet been locked. Locked sheets are not changed. |                     |                              |
| AD-06 | Users                   | Creating a staff account is immediate — the account is active straight away. There is no email-invite step. The person signs in with the password you set and can change it from their account page.                                                            |                     |                              |
| AD-07 | Grade-change approvers  | Each teacher who enters grades must have a primary and secondary approver assigned. Post-lock grade changes are routed to those two people.                                                                                                                     |                     |                              |
| AD-08 | Award thresholds        | The award thresholds (the minimum average for Bronze, Silver, and Gold) are set in SIS Admin → School Config and apply school-wide. The defaults are Bronze from 88.5, Silver from 91.5, Gold from 95.5.                                                        |                     |                              |
| AD-09 | Leave-quota defaults    | The school-wide default for vacation leave (per term) and compassionate leave (per year) is set in SIS Admin → School Config. Individual students can have a different allowance set on their own record, which overrides the school default for that student.  |                     |                              |
| AD-10 | Report-card letterhead  | The school name, address, phone, website, PEI registration number and dates, and logo shown on every report card come from SIS Admin → School Config. Changing them there updates every future report card.                                                     |                     |                              |
| AD-11 | Discount codes          | Discount codes can be managed by school admin and the admissions team. The admissions team reaches the discount codes page via a link in the Admissions sidebar. School admin reaches it via SIS Admin.                                                         |                     |                              |

## Admissions

| #     | Area                      | What the system does                                                                                                                                                                                                                                                                                                        | Correct? (Yes / No) | If not — the correct process |
| ----- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------- |
| AD-12 | Application pipeline      | An application moves through these stages in order: Submitted → Ongoing Verification → Processing → Enrolled (or Enrolled Conditional). It can also exit as Cancelled or Withdrawn at any stage. The pipeline stage is updated by the admissions team on the applicant's record.                                            |                     |                              |
| AD-13 | Document validation queue | When a parent uploads a document, it appears in the document validation queue as "Uploaded". The admissions officer works through the queue one document at a time, approving or rejecting each with a required reason.                                                                                                     |                     |                              |
| AD-14 | Chase split               | The system separates documents into two groups: "the family owes us" (status: To Follow, Rejected, or Expired — the parent needs to act) and "we owe a review" (status: Uploaded — you need to check it). The priority panel and sidebar filters follow this split.                                                         |                     |                              |
| AD-15 | Chase actions             | You can send a family an email reminder about outstanding documents directly from their record. There is a 24-hour cooldown — you cannot send another reminder to the same family within 24 hours. You can also mark a document as "Promised by [date]", which notes the family has committed to providing it by that date. |                     |                              |
| AD-16 | Applicant feedback        | Families can optionally rate the online application process from 1 to 5 and leave a comment. The Admissions sidebar has a Feedback page showing all responses, with an average rating and the comments.                                                                                                                     |                     |                              |
| AD-17 | STP / Edutrust tracking   | For international students, the system tracks the Student Pass application type and status, plus a residency history (past addresses for ICA). This is kept on the applicant's record under the STP tab.                                                                                                                    |                     |                              |
| AD-18 | ICA documents not stored  | Documents that parents submit directly to Singapore ICA (such as the ICA photo, financial support documents, and vaccination records) are not tracked or uploaded in this system. The SIS only tracks the Student Pass application status — not the individual ICA documents.                                               |                     |                              |
| AD-19 | Early-bird pipeline       | When the early-bird application window is open for next year, applications appear under Admissions → Upcoming Applications. The pipeline works the same way as the current year. The window is opened and closed in SIS Admin.                                                                                              |                     |                              |

## P-File Officer (document renewals)

| #     | Area                         | What the system does                                                                                                                                                                                                   | Correct? (Yes / No) | If not — the correct process |
| ----- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------- |
| AD-20 | Enrolled students only       | The P-Files module only shows students who are enrolled. Students who applied but have not been enrolled do not appear here.                                                                                           |                     |                              |
| AD-21 | Expiry auto-flag             | Passports, passes, and related travel documents have expiry dates. When the expiry date passes, the document status automatically changes to "Expired" — no manual action needed.                                      |                     |                              |
| AD-22 | Expiring-soon filters        | The sidebar shows quicklinks to filter students by how soon their documents expire: within 30 days, within 60 days, and within 90 days.                                                                                |                     |                              |
| AD-23 | Email reminder with cooldown | You can send a family an email reminder from a student's P-File when a document is expiring or expired. There is a 24-hour cooldown — you cannot send another reminder to the same family until 24 hours have passed.  |                     |                              |
| AD-24 | Promised-by date             | Instead of (or alongside) an email, you can mark a document as "Promised by [date]", meaning the family has told you they will provide it by that date. This is visible on the student's record and in the chase list. |                     |                              |
| AD-25 | Archived previous version    | When you replace a document with a newer file, the old file is kept as an archived version. You can view the history of all previous uploads on the student's record.                                                  |                     |                              |
