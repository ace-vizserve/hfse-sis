# HFSE SIS — User Acceptance Testing: Admin & Office

**What this is:** A checklist of system behaviours for the admin and office team to verify during the Singapore onsite training (22–26 June 2026). Each row describes one thing the system does. Run through it and mark whether it works as described.

**How to fill it in:** Write **Yes** in the "Works as expected?" column if the system behaves exactly as described. Write **No** if it doesn't — then write what actually happens (or what should happen) in the last column.

**Who this is for:** School Admin · Admissions · P-File Officer — fill the rows for your area.

---

## Admissions

| #     | Area                      | What the system does                                                                                                                                                                                                                                                                                                        | How to check it                                                                                                                                                                                                                                | Works as expected? (Yes / No) | If not — the correct process |
| ----- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ---------------------------- |
| AD-12 | Application pipeline      | An application moves through these stages in order: Submitted → Ongoing Verification → Processing → Enrolled (or Enrolled Conditional). It can also exit as Cancelled or Withdrawn at any stage. The pipeline stage is updated by the admissions team on the applicant's record.                                            | Open an applicant's record. Go to the Lifecycle tab. Change the pipeline stage and confirm it saves and updates the applicant's status in the list.                                                                                            |                               |                              |
| AD-13 | Document validation queue | When a parent uploads a document, it appears in the document validation queue as "Uploaded". The admissions officer works through the queue one document at a time, approving or rejecting each with a required reason.                                                                                                     | Go to Admissions → Document Validation. Open a document pending review. Approve one and reject one (with a reason). Confirm both disappear from the queue and the applicant's document status updates.                                         |                               |                              |
| AD-14 | Chase split               | The system separates documents into two groups: "the family owes us" (status: To Follow, Rejected, or Expired — the parent needs to act) and "we owe a review" (status: Uploaded — you need to check it). The priority panel and sidebar filters follow this split.                                                         | In Admissions, use the sidebar quicklinks "To follow", "Rejected / Expired", and "Uploaded" in turn. Confirm each shows the correct applicants based on their document status.                                                                 |                               |                              |
| AD-15 | Chase actions             | You can send a family an email reminder about outstanding documents directly from their record. There is a 24-hour cooldown — you cannot send another reminder to the same family within 24 hours. You can also mark a document as "Promised by [date]", which notes the family has committed to providing it by that date. | Open an applicant with an outstanding document. Send a reminder email. Try to send another immediately — confirm the button is disabled or shows a cooldown message. Then mark a document as "Promised by" a future date and confirm it saves. |                               |                              |
| AD-16 | Applicant feedback        | Families can optionally rate the online application process from 1 to 5 and leave a comment. The Admissions sidebar has a Feedback page showing all responses, with an average rating and the comments.                                                                                                                     | Go to Admissions → Feedback. Confirm the page shows ratings and comments from families who filled it in. Check the average rating figure.                                                                                                      |                               |                              |
| AD-17 | STP / Edutrust tracking   | For international students, the system tracks the Student Pass application type and status, plus a residency history (past addresses for ICA). This is kept on the applicant's record under the STP tab.                                                                                                                    | Open an international applicant's record. Go to the STP tab. Confirm pass type, status, and residency history fields are visible and editable.                                                                                                 |                               |                              |
| AD-18 | ICA documents not stored  | Documents that parents submit directly to Singapore ICA (such as the ICA photo, financial support documents, and vaccination records) are not tracked or uploaded in this system. The SIS only tracks the Student Pass application status — not the individual ICA documents.                                               | Open an international applicant's record. Go to the Documents tab. Confirm there is no upload slot for ICA photo, financial support, or vaccination documents.                                                                                 |                               |                              |
| AD-19 | Early-bird pipeline       | When the early-bird application window is open for next year, applications appear under Admissions → Upcoming Applications. The pipeline works the same way as the current year. The window is opened and closed in SIS Admin.                                                                                              | With an upcoming year open (early-bird on), go to Admissions → Upcoming Applications. Confirm applicants appear and stages can be updated. Confirm there is no open/close control inside Admissions itself.                                    |                               |                              |
